Лекция 3. Пределы функций

Важно: перед лекцией повторите определение непрерывности.

Определение предела

Число A называется пределом функции f(x) при x → a, если для любого ε > 0 найдётся δ > 0 …

Примеры

  • lim (x→0) sin(x)/x = 1
  • lim (x→∞) (1 + 1/x)^x = e

f(x) = (x² − 1)/(x − 1)
